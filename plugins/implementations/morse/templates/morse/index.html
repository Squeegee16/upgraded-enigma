{# RTL-SDR help modal #}
Enable RTL-SDR for Morse Receive

The pyrtlsdr Python package is not installed or the RTL-SDR device is not accessible. The plugin is running in demo mode with a synthetic CW signal.

Option 1: Add to Docker Image

Add to requirements.txt and rebuild: 

   # requirements.txt
   pyrtlsdr==0.2.93
   # Rebuild image:
   docker compose build --no-cache
   docker compose up -d
Option 2: Add Device Passthrough

Ensure RTL-SDR USB is passed to the container in docker-compose.yml: 

   services:
     app:
       devices:
         - /dev/bus/usb:/dev/bus/usb
       privileged: true
Option 3: Use Radio Mode

Connect a radio audio output to a sound card and switch the Morse plugin to Radio mode. This uses the discriminator audio instead of RTL-SDR.
