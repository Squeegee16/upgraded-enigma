{# Docker help #}
Docker Setup

OpenWebRX runs as a Docker sidecar container. Ensure it is running: 

docker compose up -d openwebrx
docker compose ps openwebrx

docker-compose.yml must include: 

openwebrx:
  image: jketterl/openwebrx:stable
  ports:
    - "8073:8073"
  volumes:
    - openwebrx_data:/var/lib/openwebrx
  devices:
    - /dev/bus/usb:/dev/bus/usb
  privileged: true
